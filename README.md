# 📅 나의 주간 루틴

초등교사이자 야간제 대학원생을 위한 **주간 반복 업무 관리 웹앱**입니다.
Windows PC와 iPhone 브라우저에서 모두 사용할 수 있습니다.

## ✨ 주요 기능

- **📌 오늘의 업무** — 오늘 요일 기준으로 해야 할 일을 시간순으로 표시
- **🗓️ 이번 주 전체** — 일~토 7일치를 한눈에, 오늘 날짜 강조
- **🌅 아침 루틴 / 🌙 퇴근 후 루틴** — 단계별 체크리스트 (월~금 표시), 진행률 바 제공
- **⏳ 다가오는 시험·과제** — D-day 카운트다운, 7일 이내 빨간 강조
- **📆 월간 달력 (9~12월)** — 화면 하단에 대학원 시험/보고서/발표 일정을 달력 형태로 표시 (색점 구분)
- **✅ 완료 체크** — 클릭으로 완료 표시, **매주 일요일 0시(토요일 자정)에 자동 초기화**
- **🧺 빨래 (주 1회)** — 일요일/수요일 중 한 번만; 한쪽에서 완료하면 그 주에는 다른 날에서 자동으로 사라짐
- **📱 반응형** — PC 7열 → 태블릿 4열 → 모바일 2열 자동 전환

## 🖼️ 화면 구성 (위 → 아래)

1. 🗓️ 이번 주 전체 (주간 그리드, 오늘 강조)
2. ⏳ 다가오는 시험·과제 (D-day)
3. 🌅 아침 루틴 / 📌 오늘의 업무 / 🌙 퇴근 후 루틴
4. 📆 대학원 일정 달력 (9~12월)

## 🗂️ 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 앱 화면 구조 |
| `style.css` | 디자인 (반응형) |
| `data.js` | 요일별 업무 / 루틴 / 시험 일정 데이터 |
| `app.js` | 렌더링 및 기능 로직 |

## 🚀 사용 방법

1. 이 저장소의 파일을 내려받거나 클론합니다.
2. `index.html`을 브라우저(Windows PC / iPhone Safari 등)에서 엽니다.
3. 끝! 별도의 설치나 서버가 필요 없습니다.

## ✏️ 내용 수정하기

업무나 일정을 바꾸고 싶으면 **`data.js`** 파일만 편집하면 됩니다.

- 요일별 업무: `WEEK_DATA` (0=일 ~ 6=토)
- 아침 루틴: `MORNING_ROUTINE`
- 퇴근 후 루틴: `EVENING_ROUTINE`
- 시험/보고서/발표 일정: `EXAMS` (`date`는 `"YYYY-MM-DD"` 형식, 미정이면 `null`)
